# Óptica Santa Clara Website

Responsive corporate website developed for **Óptica Santa Clara**, focused on presenting the brand, eyewear selection, and store locations through a polished and accessible digital experience.

## Overview

The project was designed as a real business website, combining institutional content, product presentation, responsive navigation, and location discovery for three stores in Campo Grande, Brazil.

## Features

- Responsive desktop and mobile layout
- Mobile navigation menu
- Visual eyewear and brand showcase
- Interactive store location carousel
- Google Maps route integration
- Accessible navigation and semantic structure
- Lazy-loaded visual content
- Dedicated institutional, products, highlights, locations, and contact sections

## Tech Stack

- **Next.js 16**
- **React 19**
- **TypeScript**
- **Tailwind CSS 4**
- **Vite / Vinext**

## Running Locally

Requirements:

- Node.js 22.13+
- npm

```bash
npm install
npm run dev
```

Build the project with:

```bash
npm run build
```

## Project Goal

This project was created to provide Óptica Santa Clara with a modern digital presence and make it easier for customers to explore products, understand the brand, and find the nearest physical store.
